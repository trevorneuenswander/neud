# NEUD public branding assets

Canonical artwork: `desktop/assets/icon.png` (official NEUD v0.3.0 application icon, 1024×1024).

Derived web assets in this folder and under `public/` / `src/app/` must be regenerated from that source without redesigning or recoloring the artwork.

Version query parameter used on the website: `?v=0.3.0` (see `src/lib/branding/logo.ts`).
