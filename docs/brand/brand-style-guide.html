01 — Foundation

Brand Direction

NEUD should feel like professional broadcast technology that has moved beyond traditional broadcast software: powerful, technical, and modern — but visually approachable.

PrecisionExact, controlled, intentional
DataLive signals, clarity, flow
MotionContinuous, purposeful progress
ConnectivitySystems linked in real time
Live ProductionBuilt for the control room
IntelligenceQuiet capability, not spectacle

Dark broadcast environment + luminous flowing data

The dark interface represents the professional production workspace — focused, calm, and operational. The cyan-to-violet spectrum represents live data moving through NEUD: arriving, transforming, and becoming graphics.

NEUD Brand Style Guide 05
03 — Color

The NEUD Data Spectrum

The gradient should feel continuous and luminous rather than like visible color bands. It is the signature expression of data flowing through NEUD.

Primary gradient

#35D9F5 → #1769FF → #9A8CFF → #7839F5 → #E57AF5

Horizontal continuum

Diagonal — Preferred for ribbons and hero accents.

Ribbon flow — Geometry derived from the N.

Atmospheric dark gradient

Electric Blue illumination → Midnight → Violet illumination

The center of large background gradients should usually remain dark. Keep luminosity at the edges so the interface stays operational and readable.

NEUD Brand Style Guide 10
05 — Interface

Controls & Status

Brand color and operational color serve different jobs. Never confuse them.

Primary action Secondary Destructive

Primary: bright controlled blue or blue-violet · Secondary: dark surface with subtle border · Destructive: traditional red

Live / Healthy

Green. Engines running, connections healthy, outputs live.

Warning / Pending

Yellow. Changed, unsaved, pending, or attention required.

Error / Destructive

Red. Failures, destructive actions, critical stop states.

Brand / Selection

Spectrum. NEUD identity, data emphasis, selected states.

The brand gradient should never replace universally understood operational status colors.

Gradient = NEUD / data / selection  ·  Green = Live / healthy  ·  Yellow = Warning / changed / pending  ·  Red = Error / destructive

NEUD Brand Style Guide 12
06 — Motion

The Data Ribbon

A secondary brand device derived from the geometry of the N. A thick, rounded gradient ribbon that visually represents information flowing through the NEUD ecosystem.

Use cases

  • Connect systems in diagrams
  • Wrap imagery
  • Form data paths
  • Transition between sections

Also suited for

  • Loading animation
  • Marketing graphics
  • System architecture diagrams
  • Hero compositions
Keep ribbon geometry thick, rounded, and continuous — echoing the N without copying the full logo.
