# NEUD v0.2.3

NEUD v0.2.3 is a reliability hotfix focused on fresh installations and cross-device display synchronization.

## Fixed

- Fixed published displays failing to load after installing NEUD on a new computer.
- Published display revisions now follow project/display identity changes correctly during cloud synchronization.
- Missing local published revisions can now be restored from the exact cloud revision when available.
- Stream Bid, Stream Ticker, and LED Display (Quail) now recover their published output without requiring a manual republish.
- Preview, Local URL, Pin, and Fullscreen output now resolve consistently after fresh installation.
- Added clearer diagnostics for missing or repaired published display content.

## Known issue

Windows live Broad Arrow display updates can still have more latency than macOS in some packaged workflows. Further optimization is planned.
