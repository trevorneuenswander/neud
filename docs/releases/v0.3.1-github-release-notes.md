# NEUD Alpha 0.3.1

**Status:** Published Alpha release for Windows x64 and Apple Silicon macOS.

## Highlights

- SEMA Google Sheets worksheet viewing with live-data separation, cross-tab Jump, and worksheet-aware Highlight
- SEMA ticker empty-slot fade behavior for cleaner on-air transitions
- Team Admin Users and Access for administered teams, including Hildreth Media Group workflows
- Cloud last-Team-Admin protection so demote/remove cannot leave a team without an active Admin
- Recording ↔ Output conversion persistence across Output Manager sessions
- Hosted portal Team Admin routing and clearer display-list error reporting

## Platforms

| Platform | Architecture | Artifact |
| --- | --- | --- |
| Windows | x64 | `NEUD-Setup-0.3.1-x64.exe` |
| macOS | Apple Silicon (arm64) | `NEUD-0.3.1-arm64.dmg` |

## Recording formats

- **Windows:** H.264 MP4
- **macOS:** H.264 MP4, ProRes 422 HQ, ProRes 4444

## Known limitations

- Broad Arrow Online Viewer displays remain unpublished until explicitly enabled; active cloud display records are still listed for authorized users.
- Windows ProRes **playback** requires separately staged LGPL FFmpeg shared libraries. If those DLLs are not present in the installer, ProRes playback on Windows is **not** claimed for that build.
- Windows ProRes **encoding** is not implemented.
- DeckLink Key/Fill requires compatible Blackmagic hardware and Desktop Video. Packaging gates prove a real addon binary; they do not replace a hardware Key/Fill test.
- Alpha software; unsigned Windows builds may show SmartScreen warnings.
- Intel Macs are not supported.
- macOS CI builds are unsigned/not notarized until Developer ID signing secrets are configured.

## Notes for operators

- Install Blackmagic Desktop Video before using DeckLink output.
- Preserve existing local project data when upgrading from 0.3.0.
- Cloud Team Admin membership mutations now reject operations that would remove the final active Admin.
