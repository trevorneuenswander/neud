# NEUD Alpha 0.3.1

**Status:** Prepared for release — publish only after Windows/macOS installers are verified and the owner authorizes public links.

## Highlights

- New product slogan: **Graphics Without Limits.**
- Approved application icon and color refresh
- Windows DeckLink native addon packaged as a real SDK build (not a stub)
- Windows Record to Disk: H.264 MP4 via Media Foundation
- Output Manager and Activity synchronization stability fixes
- Video playback control layout improvements

## Recording formats

- **Windows:** H.264 MP4
- **macOS:** H.264 MP4, ProRes 422 HQ, ProRes 4444

## Known limitations

- Windows ProRes **playback** requires separately staged LGPL FFmpeg shared libraries. If those DLLs are not present in the installer, ProRes playback on Windows is **not** claimed for that build.
- Windows ProRes **encoding** is not implemented.
- DeckLink Key/Fill requires compatible Blackmagic hardware and Desktop Video. Packaging gates prove a real addon binary; they do not replace a hardware Key/Fill test.
- Alpha software; unsigned Windows builds may show SmartScreen warnings.
- Intel Macs are not supported.

## Notes for operators

- Install Blackmagic Desktop Video before using DeckLink output.
- Preserve existing local project data when upgrading from 0.3.0.
