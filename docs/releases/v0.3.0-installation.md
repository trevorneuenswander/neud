# NEUD Alpha 0.3.0 — Installation and upgrade

## Platforms

| Platform | Artifact | Architecture | Notes |
| --- | --- | --- | --- |
| Windows | `NEUD-Setup-0.3.0-x64.exe` | x64 | SmartScreen may warn on unsigned Alpha builds |
| macOS | `NEUD-0.3.0-arm64.dmg` | Apple Silicon (arm64) | Intel Macs are not supported |

## Fresh install

### Windows

1. Download `NEUD-Setup-0.3.0-x64.exe` from the [download page](https://neud.io/download) or the GitHub Release.
2. Run the installer. Existing `%APPDATA%\NEUD\` data is preserved across upgrades.
3. Launch NEUD and sign in.

### macOS

1. Download `NEUD-0.3.0-arm64.dmg`.
2. Open the disk image and drag **NEUD** to Applications.
3. On first launch, Gatekeeper may require **Open** from System Settings → Privacy & Security if the build is unsigned.
4. Launch NEUD and sign in.

## Upgrade from v0.2.1 (or any 0.2.x)

1. Quit NEUD completely.
2. Install 0.3.0 over the existing installation (Windows NSIS) or replace the app in Applications (macOS).
3. Launch once. SQLite migrations apply automatically.
4. Verify projects, displays, pinned stacks, and account access.

### Preserved

- Local projects and displays
- Credentials and account access
- Local data and exports
- User settings
- Project package installation state (packages remain independently versioned)
- Cloud synchronization behavior

### Not wiped

- Local SQLite databases under the NEUD application data directory
- Published display revisions already synced

## Record to Disk

Supported and validated on **macOS** in this release:

- H.264 MP4
- ProRes 422 HQ MOV
- ProRes 4444 MOV

Windows recording is **not claimed** in v0.3.0.

## Hardware features

DeckLink Key/Fill and external monitor output require compatible hardware. Automated CI does not validate physical DeckLink devices.

## Next version (not in 0.3.0)

Display Transforms, IN/OUT Transitions, and Stream Deck integration remain on the post-0.3.0 roadmap.
