# NEUD v0.2.4

NEUD v0.2.4 is a reliability and workflow update focused on cross-device consistency, live auction operation, macOS behavior, and controller polish.

## Highlights

- Improved Stream Bid lot transitions so photos from the previous lot cannot reappear after advancing.
- Improved macOS browser detection and recovery when a cached Chrome installation is incomplete.
- Added complete Manual Bid clearing from the Local Controller and live displays.
- Signing out now warns when the scraper is running and safely stops active data engines before ending the session.
- Improved collapsed sidebar behavior.
- Fixed project team names in user Associated Projects.
- Improved Activity table column proportions.
- Display enabled/disabled state and display order now synchronize across NEUD installations.
- Fixed Stream Bid Local URL background parity with Preview, Fullscreen, and pinned output.
- Improved fresh-install display synchronization and published display hydration.

## Cross-platform

- Windows 10/11 x64 and Apple Silicon macOS are supported.
- Live display updates were validated at low latency on a clean Windows installation and on macOS.
- Machine/environment-specific latency was observed on one Windows system and was not reproduced on a clean Windows laptop. Diagnostics remain available.

Intel Macs are not supported.
