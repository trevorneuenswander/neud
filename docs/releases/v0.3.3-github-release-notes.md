# NEUD Alpha 0.3.3

**Version:** 0.3.3  
**Base:** v0.3.2  
**Status:** Published  

## Highlights

### Mic Tally status colors
- **LIVE** uses bright red `#FF2020` for clear on-air visibility.
- **MUTED** and **FADER DOWN** use muted green `#527D65`.
- **UNKNOWN** remains gray `#777777`.
- Existing customized Mic Tally displays are preserved; stock bundled UHD Mic Tally upgrades safely.

### Simultaneous Blackmagic UltraStudio outputs
- Multiple UltraStudio (and other DeckLink) outputs can stay **LIVE at the same time**.
- Each device uses an independent native session — starting or stopping one output no longer tears down another.
- Frame delivery, stop, and metrics are scoped per endpoint.
- Independent graphics, modes, and Key/Fill continue to work per output.

### Output rename focus
- Renaming an Output no longer loses keyboard focus after every character.
- Continuous typing, normal editing, save, and persistence work as expected.
- Renaming while outputs are LIVE does not stop or restart active DeckLink sessions.

### SEMA Schedule Ticker marquee
- Fixed title/description sizes: **57px / 52px** (no shrink-to-fit).
- Overflow uses Broad Arrow–style marquee at **40px/s** with 1s ease and 4s holds.
- Title and description animate independently.
- Adding or removing Highlight does **not** restart unrelated marquees.
- Stock installs safely upgrade from v0.3.2 and from the intermediate v0.3.3-dev ticker revision.

### SEMA Fullscreen Schedule marquee
- Preserves original NOW/NEXT/LATER typography (196/90, 128/74, 108/66).
- Overflow marquee with independent field controllers and highlight-stable animation.
- Marquee travel speed **50px/s** (ease and 4s holds unchanged).
- Stock installs safely upgrade from v0.3.2 and from the prior 40px/s highlight-stable revision.

## Notes

- Local projects, displays, settings, and Output assignments from v0.3.2 are preserved on upgrade.
- Requires Blackmagic Desktop Video for DeckLink / UltraStudio hardware.
- Intel Macs are not supported.
- No production SQL migrations were added in this release.
