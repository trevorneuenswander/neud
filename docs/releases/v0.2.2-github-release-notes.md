# NEUD v0.2.2
## Cross-Platform Alpha

**Release date:** September 26, 2026

NEUD is now available for **Windows x64** and **Apple Silicon (arm64) Macs**. This release expands NEUD's cross-platform desktop foundation while improving live-data reliability, authentication, packaged browser support, display recovery, and diagnostics. It also includes **LED Display (Quail)** for Broad Arrow workflows.

## Highlights

- Apple Silicon macOS support
- Windows + macOS packaged desktop builds
- LED Display (Quail)
- Packaged Faye/event-driven scraper parity
- Authentication and runtime configuration hardening
- Packaged Chrome cross-platform improvements
- Fresh-install display output hydration
- Improved scraper/runtime diagnostics
- Display transport and SSE reliability improvements
- macOS-native menu/window behavior

## Platform availability

- **Windows:** x64 (`NEUD-Setup-0.2.2-x64.exe`)
- **macOS:** Apple Silicon / arm64 (`NEUD-0.2.2-arm64.dmg`, zip for updates)

## macOS signing

macOS builds from CI are **unsigned and not notarized** until Developer ID credentials are configured. Gatekeeper may block or require manual approval on first open. See the download page for guidance.

## Known issue

**Windows packaged live graphics** can update more slowly than macOS during live Faye workflows. Faye itself is functioning; additional Windows display transport optimization is planned. Diagnostics remain enabled for investigation.
