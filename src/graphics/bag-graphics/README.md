# BAG-Graphics

Web code for the `bag-graphics` project type.

BAG-Graphics monitors an auction website and provides live lot, bid, and sold information for broadcast overlays.

Subdirectories:

- `components/` — BAG-specific React components
- `controller/` — web controller UI
- `display/` — OBS-compatible graphic displays
- `types/` — BAG-specific TypeScript types
- `validation/` — BAG-specific input validation
